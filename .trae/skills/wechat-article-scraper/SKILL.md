# 公众号文章抓取与分析工具

## 功能说明

此工具可以通过API抓取公众号文章，并对每篇文章进行分析，重点关注农药相关内容，包括：
- 农药畅销品排名
- 农药畅销品好评及差评
- 农药与肥料协同增效
- 农药最新的技术实践

最后根据分析结果生成符合2026年最新样式的HTML报告。

## 使用方法

1. 输入格式：`【Skill】` 加上您的具体需求
2. 工具会自动调用API抓取相关文章
3. 对每篇文章进行分析和评分
4. 生成HTML报告并呈现给您

## API配置

- **API Key**: JZL05e325094f052b92
- **接口地址**: /fbmain/monitor/v3/kw_search
- **请求参数**:
  - kw: 关键词
  - sort_type: 排序方式（1：阅读数，2：时间）
  - mode: 搜索模式（1：标题，2：正文，3：标题和正文）
  - period: 时间范围（1-7天）
  - page: 页码
  - key: API Key
  - any_kw: 任意关键词
  - ex_kw: 排除关键词

## 分析逻辑

1. **关键词匹配**：
   - 农药畅销品排名
   - 农药畅销品好评及差评
   - 农药与肥料协同增效
   - 农药最新的技术实践

2. **评分标准**：
   - 相关性：0-40分
   - 内容质量：0-30分
   - 时效性：0-20分
   - 数据完整性：0-10分

3. **HTML报告生成**：
   - 2026年最新样式
   - 响应式设计
   - 数据可视化
   - 详细分析结果
