# 公众号文章抓取与分析工具

## 功能介绍

此工具可以通过API抓取公众号文章，并对每篇文章进行分析，重点关注农药相关内容，包括：
- 农药畅销品排名
- 农药畅销品好评及差评
- 农药与肥料协同增效
- 农药最新的技术实践

最后根据分析结果生成符合2026年最新样式的HTML报告。

## 安装依赖

```bash
pip install requests
```

## 使用方法

### 1. 直接调用Python脚本

```bash
python scraper.py
```

默认会抓取关键词"农药 畅销"的文章，你可以修改脚本中的`main`函数调用来自定义关键词。

### 2. 作为Skill使用

在Trae IDE中，输入：

```
【Skill】抓取最近7天关于农药畅销品的公众号文章，并分析其排名和评价
```

工具会自动调用API抓取相关文章，分析内容，并生成HTML报告。

## 注意事项

1. 每次调用会消耗API点数（0.02元/条）
2. 建议设置合理的关键词和时间范围，避免返回过多无关内容
3. 分析结果仅供参考，具体决策请结合实际情况
4. 由于API限制，建议不要频繁调用，每次调用间隔至少2秒

## 故障排除

1. **API调用失败**：检查网络连接，API Key是否正确
2. **返回数据为空**：尝试调整关键词，或者扩大时间范围
3. **报告生成失败**：检查Python环境是否正确安装了requests库
